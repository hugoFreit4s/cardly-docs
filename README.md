# Cardly — documentação

Repositório de documentação e planejamento do projeto Cardly (não contém código da aplicação).

## Repositórios técnicos

| Repositório | Descrição |
|-------------|-----------|
| [cardly-backend](https://github.com/hugoFreit4s/cardly-backend) | API Spring Boot |
| [cardly-rnative-app](https://github.com/hugoFreit4s/cardly-rnative-app) | App React Native / Expo |

## Conteúdo deste repositório

| Pasta / arquivo | Descrição |
|-----------------|-----------|
| [already-done.md](already-done.md) | Histórico do que já foi implementado (atualizar após cada `fixes/v*.md`) |
| [todo.md](todo.md) | Backlog e requisitos gerais |
| [rules.md](rules.md) | Regras de commit e convenções do time |
| [fixes/](fixes/) | Planos de correções e features por versão (`v1.md` … `v7.md`) |
| [docs/report/](docs/report/) | Relatório técnico ABNT (LaTeX) |
| [agents/](agents/) | Contexto para agentes (backend e frontend) |
| [cursor/](cursor/) | Planos e regras Cursor (referência) |
| [assets/](assets/) | PDFs de apoio (flashcards, template institucional) |

## Fluxo de trabalho

1. Implementar mudanças nos repositórios técnicos.
2. Registrar o que foi feito em `already-done.md` (seção `## vN — …`).
3. Manter `fixes/vN.md` como registro do pedido original.
